1. Pick your cropped question images

Choose a whole folder (e.g. Physics/Laws of Motion/q012.png) — subject and topic are read from the folder names and can be edited below. One question is created per image; the image is the question, so options come from the picture — students will just see generic Option 1 / Option 2 / Option 3 / Option 4 choices instead of lettered ones. Images are auto-compressed to fit Firestore's 1 MB per-question limit. The correct answer is read straight out of each filename (e.g. Q12_B.jpg, Q12(2).png, Q12_key3.jpg all work) — no separate key needed for most sets; step 2 below is only a fallback for rows it couldn't read.

2. Paste the answer key

Any usual format works: 1-A 2-C 3-B, 1. A, 1,A (one per line), or a plain run of letters ABCDACBD…. Numbers are matched to the number found in each filename; if filenames have no numbers, the key is applied in listed order.

🤖 AI follow-up drafts

For tests with AI follow-up switched on, each submission is queued. An hourly job waits up to 2 hours for the student's reasons, then one AI writes practice questions aimed at their mistakes and a second AI solves each one blind to check the key: ✅ Verified both agree · ⚠ Disputed they disagree · ❌ Rejected flawed (left out). Review opens the draft in the Diagnostic Builder — edit, delete, fix keys, then Save and publish to that student.

Custom practice tests from mistakes

For each student who took a test, builds a follow-up test from the questions they got wrong or skipped, using the reason they gave after the test (or their timing, if they gave none): concept gap → same topic from Bloom Level up to the question's level · accuracy slip (misread, calculation, silly) → same topic at the same level · speed (ran out of time, too lengthy) → same topic, same or easier level, with ideal time shown. Questions come from the bank via the practice index (Topics → Rebuild practice index if new questions are missing). Each test is assigned only to that student.
