1. Pick your cropped question images

Choose a whole folder (e.g. Physics/Laws of Motion/q012.png) — subject and topic are read from the folder names and can be edited below. One question is created per image; the image is the question, so options come from the picture. Images are auto-compressed to fit Firestore's 1 MB per-question limit.

2. Paste the answer key

Any usual format works: 1-A 2-C 3-B, 1. A, 1,A (one per line), or a plain run of letters ABCDACBD…. Numbers are matched to the number found in each filename; if filenames have no numbers, the key is applied in listed order.

3. Review & import

Patch answer key on an existing bank

Fixes correct_answer on questions already uploaded — useful when a test went up with placeholder answers. Pick the exam (or a whole subject bank), paste the official key, preview what will change, then apply.
